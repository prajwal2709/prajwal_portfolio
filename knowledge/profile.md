# Crop Disease Detection
Code: https://github.com/prajwal2709/crop-disease-detection
A farmer-friendly web app that identifies crop diseases from leaf images. Image preprocessing and model training use the PlantDoc dataset. A MobileNetV2 model is served by a Flask backend API with a React + Vite frontend. It reached 95.05% test accuracy. Tech: Python, TensorFlow, MobileNetV2, scikit-learn, Flask, React.

# Multimodal RAG System
Code: https://github.com/prajwal2709/MultiModal_Rag
A RAG system that retrieves information from PDF documents using both text and images. It extracts PDF text and images with PyMuPDF, chunks text, and creates embeddings with Sentence Transformers and CLIP. ChromaDB stores the vectors for semantic retrieval. Answers are generated through OpenRouter using the retrieved context.

# AI Wedding Planner
Code: https://github.com/prajwal2709/AI-Wedding_Planner
A research-assisted wedding planning workspace built with Streamlit and a LangChain multi-agent workflow. A main planner agent coordinates two research subagents that use Tavily web search to gather current venue and vendor information, then combines the research into a tailored plan that can be downloaded as Markdown. The agents use Groq-hosted openai/gpt-oss-120b.
